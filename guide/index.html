教學

審判工具箱每個工具的詳細教學：分步驟說明，每一步附畫面。簡短的步驟在使用說明。

入門

  • 第一次使用審判工具箱：放入 PDF、三個步驟與輸出位置審判工具箱的入門教學。說明首頁的四組工具、放入 PDF 的三種方法、每個工具共通的三個步驟、輸出前的檔案清單、輸出的檔案存在哪裡，以及有密碼的檔案與掃描頁怎麼處理。

判決連到司法院裁判書查詢網站

  • 到司法院網站找判決並批次下載：判決下載教學用審判工具箱的「判決下載」，依法院、裁判日期、關鍵字搜尋司法院公開的判決，先看全文、勾選要的，再一次下載成 PDF、Markdown，或每幾份合併成一個 PDF。這篇也說明搜尋不到時可能的原因。

讀卷閱卷回來，先把卷整理成找得到東西的樣子

  • 替整卷卷證加上書籤：書籤形成教學用審判工具箱的「書籤形成」，把一整卷卷證分出起訴書、筆錄、書狀等每一份文件，依證據類型加上書籤。這篇說明放入、核對清單、改名與移除，以及三種輸出的差別。
  • 依陳述人分開筆錄：供述切割教學用審判工具箱的「供述切割」，把幾卷卷證裡的筆錄依陳述人分開，同一個人在不同卷裡的筆錄放進同一個 PDF。這篇說明放入幾卷、核對陳述人、修改與排除、四個分檔設定，以及輸出的檔案。
  • 幾卷一起找關鍵字：全文搜尋教學用審判工具箱的「全文搜尋」，把幾卷卷證放在一起找關鍵字，看每一處在哪一卷第幾頁，點一筆就顯示那一頁。這篇說明放入、建立搜尋資料、幾個詞一起找、看命中的頁面，以及搜尋資料存在哪裡、怎麼清除。
  • 把卷證轉成文字檔：PDF 轉 Markdown 教學用審判工具箱把卷證 PDF 轉成 Markdown 文字檔。這篇照順序說明放入卷證、對照原頁面預覽、四個轉換設定、輸出的檔案長什麼樣子，以及掃描頁要注意的地方。
  • 照章節標題把一份 PDF 切開：章節切割教學用審判工具箱的「章節切割」，照 PDF 的書籤或「壹、貳」「第一章」這類章節標題，把一份 PDF 切成每章一份 Markdown 文字檔，另附目錄索引。這篇說明切到第幾層、核對章節、不要某一段，以及輸出的格式。
  • 讓掃描的卷證可以搜尋、複製：可搜尋 PDF 教學用審判工具箱的「可搜尋 PDF」，把掃描頁辨識出的文字用看不見的文字層寫回 PDF。頁面看起來不變，但在 PDF 閱讀程式裡可以搜尋、反白、複製。這篇也說明辨識要多久、辨識錯時會怎樣。

遞狀與交付要送出去之前

  • 把證物編號、合成一冊並加目錄：證物冊教學用審判工具箱的「證物冊」，把幾份證物 PDF 排好順序，蓋上「原證 1」「被證 1」這類編號，合成一冊，最前面加證物目錄、全冊連續頁碼。這篇說明排順序、編號設定、目錄與每件各一份的輸出。
  • 把卷證裡的個資換成代號：去識別化教學用審判工具箱找出卷證裡的姓名、身分證字號、電話、地址等個資，逐項確認後，輸出換成「姓名A」這類代號的文字檔；之後再用「還原」把含代號的文字換回原文。這篇也說明它會漏掉哪些個資。
  • 替 PDF 每一頁加頁碼、流水號或浮水印：頁碼與浮水印教學用審判工具箱的「頁碼與浮水印」，在 PDF 的每一頁加上「第 N 頁」或「ABC000001」這類流水號，也可以加上「僅供閱卷使用」這類浮水印。這篇說明各個選項、預覽，以及加上去之後要注意的地方。
  • 替 PDF 加上或拿掉開啟密碼：密碼教學用審判工具箱打開有開啟密碼的 PDF、替 PDF 加上開啟密碼（AES-256），或另存一份沒有密碼與限制的版本。這篇說明放入時怎麼輸入密碼、兩種用途的設定，以及忘記密碼時沒有辦法救回。

頁面零碎的整理

  • 合併、拆分、刪頁：頁面整理教學用審判工具箱的「頁面整理」看縮圖合併幾份 PDF、拆開、重排、旋轉、刪頁，並找出疑似空白的頁。這篇說明每個按鈕的用法、四種輸出方式，以及找空白頁要人確認的原因。
  • 圖片轉 PDF、PDF 轉圖片：圖片與掃描教學用審判工具箱把幾張圖片合成一份 PDF、把 PDF 每一頁存成圖片，或把大小不一的頁面縮放成 A4；iPhone・iPad 還可以用相機掃描紙本。這篇說明三種做法的設定與輸出。

其他

  • 請 AI 工具整理輸出的卷證：交給 AI 教學（Mac）審判工具箱 Mac 版的「交給 AI」，會產生一段指示放進剪貼簿，讓你貼到自己用的 AI 工具，請它整理輸出的檔案。這篇說明怎麼選範圍與任務、個資提醒的意思，以及「去識別化 → 交給 AI → 還原」的做法。
  • 在手機與平板上整理卷證：iPhone・iPad 使用教學審判工具箱 iPhone・iPad 版的用法：首頁與相機掃描、從「檔案」App 放入 PDF、清單與整頁預覽、輸出的檔案在哪裡、iPad 的版面，以及廣告與「去除廣告」。
